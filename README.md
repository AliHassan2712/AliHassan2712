## 👨‍💻 About Me

I am a **Computer Systems Engineer** graduated from **Al-Azhar University**, specializing in modern **Frontend Engineering** with **React.js (React 19)**, **Next.js (App Router)**, and **TypeScript**. 

I have hands-on experience building high-performance B2B SaaS platforms, real-time IoT & telemetry dashboards, and scalable web apps. I focus on clean code, seamless API integrations, server-state caching (TanStack Query), responsive UI design, and rigorous testing.

- 🔭 **Currently working on:** Core frontend features for **Zimam** (B2B Multi-tenant Fleet Management SaaS).
- 💼 **Open to:** Frontend Developer & Full-Stack (Next.js) Engineering opportunities.
- ⚡ **Superpowers:** React 19, Next.js App Router, TanStack Table/Query, Real-Time Leaflet & WebSockets, Performance Optimization (Web Vitals).
