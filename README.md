## Featured Engineering Projects

<div align="center">

  ### [Compressor Dashboard Platform](https://github.com/AliHassan2712/Dashboard)
  *High-performance media compression & analytics dashboard built for speed and efficiency.*<br>
  Engineered an interactive analytics and file-processing dashboard using **Next.js**, **React.js**, and **TypeScript**. Implemented batch asset compression workflows, real-time file size & reduction metrics, optimized memory consumption, and dynamic responsive data visualization.

  <br>

  ### [Subscriptions Store Platform](https://github.com/AliHassan2712/subscriptions-store)
  *Enterprise-grade e-commerce system for digital subscriptions & automated order flows.*<br>
  Built with **Next.js 14 App Router**, **TypeScript**, **Prisma ORM**, and **Supabase (PostgreSQL)**. Implemented strict **Clean Architecture**, **Service Layer Abstraction**, **Zod** schema validation, and custom **Toast Notification System**.

  <br>

  ### [Tawjihi: Academic Management Reimagined](https://github.com/AliHassan2712/Tawjihi)

  <br>
